# CODSOFT Data Science Internship

My tasks for the CodSoft Data Science internship.

## Task: Iris Flower Classification
-Goal: Classify iris flowers into setosa,versicolor and virginica using sepal and petal measurements
-Models used: KNN, Logistic Regression, Random Forest
-Libraries: Python, Pandas, Seaborn, Scikit-learn
-Cross-validation accuracy :KNN 97.3%, Logistic Regression 97.3%, Random Forest 96.7%
-File: Task_1_iris_classification.ipynb

## Task: Titanic Survival Prediction
- Goal: Predict whether a passenger survived
- Models used: Logistic Regression, Random Forest
- Cleaning: filled Age (median) and Embarked (mode), dropped Cabin
- Cross-validation accuracy: Logistic Regression 79.1%, Random Forest 80.8%
- Insight: Women and First class passengers had higher survival chances

 ## Task: Sales Prediction
- Goal: Predict Sales from TV, Radio and Newspaper advertising spend
- Models used: Linear Regression, Random Forest Regressor
- Metrics: R2 score, RMSE
- Insight: TV advertising has the strongest effect on sales (correlation 0.9), Newspaper the weakest (0.16)
- File: Task_3_Sales_Prediction.ipynb
